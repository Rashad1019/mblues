# How Memphis Became Memphis — An I Knot Report

A historical report on the roots of urban violence in Memphis, Tennessee. This project is an interactive, single-page web report that traces the historical thread of Memphis from 1739 to the present day, exploring how systemic policies, redlining, mass incarceration, and deindustrialization have shaped the city.

## Features
- **Interactive Thread**: A reading progress thread tracking your journey through the chapters.
- **Data Visualizations**: Includes stylized, interactive maps of 1935 HOLC redlining and animated charts.
- **Responsive Design**: Built with vanilla HTML, CSS, and minimal JS for an immersive experience across devices.

## Usage
Simply open `index.html` in any modern web browser to view the report.
